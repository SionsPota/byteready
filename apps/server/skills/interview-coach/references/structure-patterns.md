# Self-Introduction Structure Patterns & Templates

Ready-to-use structure frameworks for different durations and role types.

## Universal 3W Formula

适用于所有岗位类型的底层逻辑框架：

- **Who** (我是谁): 姓名 + 身份定位 + 核心标签，10-20秒
- **Why** (为什么来): 选择该行业/公司/岗位的原因，20-30秒
- **What** (带来什么价值): 核心能力 + 关键经历 + 成果数据，60-120秒

## 1-Minute Version (群面/初面/电话面)

核心要求：**高度精炼，一击即中**。只保留最核心、最匹配的信息。

### 技术岗模板

```
"面试官您好，我是[姓名]，[年份]届毕业生，应聘[岗位]。

我主攻[技术方向]，熟练掌握[核心技术栈，3-5个关键词]。
在[公司/学校]期间，我负责[系统/模块]，通过[关键技术/方法]，
将[核心指标]提升了[具体数据]。

我关注贵司的[具体技术/产品/业务]很久了，
我的技术栈与这个岗位高度匹配，非常期待能加入团队。"
```

### 综合岗模板

```
"面试官您好，我是[姓名]，毕业于[学校/专业]，应聘[岗位]。

我拥有[X年]的[岗位相关]经验，擅长[核心能力1]和[核心能力2]。
在[经历]中，我通过[行动]，实现了[量化成果]。

我非常认同贵司[价值观/产品理念]，
相信我的[某项能力]能为团队带来直接价值。"
```

### 应届生模板（无经验版）

```
"面试官您好，我是[姓名]，[学校][专业]应届生。

在校期间，我专注[方向]，通过[项目/竞赛/论文]，
掌握了[核心技能]。例如在[项目]中，我负责[角色]，
运用[技术/方法]，达成了[成果]。

我积极关注[行业/公司]动态，是贵司产品的深度用户，
希望能以[某能力]为切入点，加入团队共同成长。"
```

## 2-Minute Version (最常用 - 业务面)

核心要求：**完整但有重点**，用STAR法则展开1-2个核心亮点。

### 技术岗模板（OKR + STAR混合）

```
"面试官好，我是[姓名]，[年份]届，应聘[岗位]。
我从3个维度介绍自己：技术栈、项目经历、岗位匹配度。

[技术栈 - 20秒]
我主攻[方向]，技术栈包括[语言][框架][中间件][工具]。
对[某技术]有深入实践，曾阅读过[源码/论文]。

[项目经历 - 60秒，STAR法则]
最有代表性的项目是在[公司]做的[系统名称]。
背景是[业务痛点]，我的目标是[解决什么问题]。
我采用了[技术方案]，过程中克服了[难点]，
最终将[核心指标]从X提升到Y，[另一指标]降低了Z%。

[岗位匹配 - 10秒]
贵司这个岗位需要的[技术/能力]正是我的强项，
非常期待能加入团队，用[某能力]解决实际问题。"
```

### 综合岗模板（钩子 + OKR）

```
"面试官好，我是[姓名]。
我想用3个关键词概括自己：[能力标签1]、[能力标签2]、[特质标签]。

[经历1 - 40秒]
在[公司]做[岗位]时，我负责[职责范围]。
目标是提升[业务指标]，我做了[具体行动1]和[行动2]，
最终实现了[量化成果]，获得了[认可/奖励]。

[经历2 - 30秒]
另一个关键经历是[项目]，目标是[目标]。
我协调了[X个部门]，通过[方法]，达成了[结果]。
这个过程锻炼了我的[某软技能]。

[个人特质 - 10秒]
我的MBTI是XX，习惯[工作风格]，
擅长在[某场景]中发挥作用。

[动机 - 10秒]
我深度使用贵司产品[多久]，特别欣赏[某点]，
希望能以[能力]贡献团队。"
```

## 3-Minute Version (终面/高管面/有丰富经验者)

核心要求：**深度叙事，展现完整能力图谱**。

### 技术岗模板

```
"面试官好，我是[姓名]，[年份]届，[学校][专业]。
我从技术栈、核心项目、技术影响力、岗位匹配4个方面介绍。

[技术栈 - 30秒]
我的技术主攻方向是[方向]，包括：
- 语言层：[语言及熟练度]
- 框架层：[框架及经验深度]
- 中间件：[存储/缓存/消息队列等]
- 基础设施：[云原生/DevOps等]
- 工程能力：[测试/监控/CI/CD]

[核心项目1 - 60秒，STAR]
在[公司]负责的[系统]，[背景]。目标是[目标]。
技术挑战是[难点]。我设计了[方案]，采用[技术栈]，
实现了[架构图简述]。
最终[核心指标]提升[数据]，[稳定性/扩展性]达到[标准]。
这个项目让我深入理解了[技术原理]。

[核心项目2 - 30秒]
另一个项目是[名称]，目标是[目标]。
我主导了[某决策]，克服了[困难]，达成了[成果]。

[技术影响力 - 20秒]
我热爱技术分享，在[平台]有[X篇]技术文章，[访问量]。
开源贡献：[项目名]，[star数]/[贡献内容]。

[岗位匹配 - 20秒]
贵司的[业务/技术方向]与我的[某经验]高度契合。
我期待将[某能力]带到团队，解决[某类问题]。"
```

## 开场钩子技巧 (Hook Opening)

3种方式抓住面试官注意力（适用于综合岗/产品/运营）：

1. **匹配度锚定**："我将从3个点，说明我和这个岗位的匹配度"
2. **反常识表达**："作为实习生，我独立负责了XX项目的全流程上线"
3. **价值观共鸣**："我是个'结果导向'的人，贵公司'用户第一'的价值观和我完全契合"

## 技术岗 vs 综合岗内容侧重点

| 维度 | 技术岗 | 综合岗 |
|------|--------|--------|
| 核心展示 | 技术深度 + 架构能力 | 业务洞察 + 影响力 |
| 数据类型 | QPS、延迟、可用性、代码质量指标 | DAU、转化率、ROI、用户满意度 |
| 经历组织 | 按技术难度/复杂度排序 | 按业务影响/成果大小排序 |
| 关键词 | 高并发、分布式、微服务、性能优化 | 用户增长、商业化、策略、跨部门协同 |
| 结尾重点 | 技术热情 + 解决复杂问题的渴望 | 业务热情 + 对公司的认同 |

## 禁止清单 (Never Do)

1. **背诵简历**：面试官手里有简历，口头介绍应提供简历上没有的深度
2. **流水账**：按时间顺序罗列所有经历，没有重点
3. **假大空**："我勤奋好学、善于沟通、团队精神强"——没有证据支撑的形容词
4. **过度谦虚**："我可能还有很多不足""我学校一般"——自我减分
5. **过度冗长**：超过约定时间，不察言观色
6. **偏离岗位**：讲大量与应聘岗位无关的经历（如面技术岗大讲社团活动）
7. **缺乏数据**："做了很多优化""提升了性能"——没有具体数字
8. **公司研究不足**："因为贵公司是大厂"——动机太泛
9. **负面信息**：抱怨前公司、前同事、前领导
10. **跑题**：讲个人生活、婚姻状况、家庭情况等无关信息
