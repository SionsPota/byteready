# Interview Self-Introduction Evaluation Rubric

Detailed scoring criteria for each of the 5 evaluation dimensions.

## Dimension 1: Structure & Logic (权重 20%)

评估自我介绍的结构清晰度、时间管理和逻辑连贯性。

### 评分标准

| 分数 | 描述 |
|------|------|
| 5分 | 结构完美：开头有钩子，中间有清晰层次（按时间/能力/项目），结尾有力；时间控制精准；过渡自然流畅 |
| 4分 | 结构清晰：开头-主体-结尾完整，层次分明；时间基本合理；偶有小的跳跃 |
| 3分 | 结构尚可：有基本的开始和结束，但中间逻辑不够清晰；时间可能略有偏差 |
| 2分 | 结构混乱：想到哪说到哪，缺乏明显的组织；时间控制差（过长或过短） |
| 1分 | 无结构：纯流水账或背诵简历，面试官无法抓取重点 |

### 关键检查点

- **开头**：是否有吸引注意力的开场（钩子）？是否快速建立身份定位？
- **主体**：是否有明确的组织逻辑（时间线/能力模块/项目优先级）？
- **结尾**：是否有力收尾？是否表达加入意愿？
- **时间**：1分钟版60秒±10秒，2分钟版120秒±15秒，3分钟版180秒±20秒
- **过渡**：段落之间是否有自然的连接词或过渡句？

### 常见结构框架

**技术岗推荐结构**：
```
[10s] 身份定位 → [20s] 技术栈 → [60s] 项目经历(STAR) → [10s] 自我评价 → [可选10s] 结尾
```

**综合岗推荐结构**：
```
[20s] 钩子开场 → [10s] 身份 → [50s] 核心经历(OKR) → [20s] 个人特质 → [20s] 动机
```

## Dimension 2: Content & Relevance (权重 30%)

评估内容质量、与岗位的相关度、以及亮点突出程度。

### 评分标准

| 分数 | 描述 |
|------|------|
| 5分 | 内容精准：每个点都高度匹配JD关键词；用STAR/OKR法则描述经历；有量化数据支撑；主动埋设钩子引导面试官提问 |
| 4分 | 内容扎实：大部分内容与岗位相关；有数据支撑；能体现个人价值；有1-2个亮点 |
| 3分 | 内容一般：与岗位有一定关联；数据较少；亮点不够突出；部分内容冗余 |
| 2分 | 内容薄弱：大量无关内容；缺少数据；看起来像在读简历；没有亮点 |
| 1分 | 内容无效：完全跑题；或过于简短没有实质内容；或过度吹嘘不可信 |

### 关键检查点

- **JD匹配度**：是否融入了目标岗位JD中的关键词？
- **数据支撑**：是否有具体的数字/百分比/规模（如"日活提升30%""QPS从1000提升到5000"）？
- **STAR法则**：经历描述是否包含 Situation-Task-Action-Result？
- **简历差异化**：是否避免了简单重复简历内容，而是提供了简历上没有的深度信息？
- **钩子设置**：是否有意设置了1-2个引导面试官后续提问的点？

### 技术岗内容重点

1. **技术栈**：语言、框架、中间件，要与岗位技术栈高度重叠
2. **项目深度**：遇到的难点、解决方案、技术选型理由
3. **技术成果**：性能优化数据、架构改进效果、代码质量提升
4. **开源/博客**：GitHub star数、博客访问量、技术社区贡献

### 综合岗内容重点

1. **业务理解**：对行业、公司、产品的认知
2. **项目成果**：用OKR框架描述 Objective + Key Results
3. **跨部门协作**：沟通协调能力、资源整合能力
4. **创新思维**：提出的创新方案、带来的业务增长

## Dimension 3: Expression & Delivery (权重 15%)

评估语言表达的流畅度、专业度和感染力。

### 评分标准

| 分数 | 描述 |
|------|------|
| 5分 | 表达精湛：语言自然不生硬；关键词重音突出；长短句交替有节奏；专业术语使用准确；有个人风格 |
| 4分 | 表达良好：语言流畅；重点有强调；专业用语恰当；听起来舒适自然 |
| 3分 | 表达一般：基本通顺但略显平淡；偶有书面语痕迹；节奏单一 |
| 2分 | 表达较差：明显像背诵；书面语过重；语调平淡缺乏变化；有口头禅或冗余词 |
| 1分 | 表达糟糕：磕磕巴巴；完全像念稿；专业术语用错；语言组织混乱 |

### 关键检查点

- **自然度**：读起来像口语还是书面语？面试是口头表达，应避免复杂从句
- **关键词强调**：重要数据和技能是否有意加强了语气（通过文字能感受到重音）？
- **节奏感**：句子长度是否有变化？是否有适当的停顿暗示？
- **专业度**：术语使用是否准确？是否体现了行业认知？
- **亲和力**：是否过于正式而显得生硬？是否过于随意而显得不专业？

## Dimension 4: Confidence & Presence (权重 20%)

评估自我介绍传递的自信程度和个人气场。

### 评分标准

| 分数 | 描述 |
|------|------|
| 5分 | 气场强大：语气坚定有力；对自己的能力有清晰认知；既不卑微也不傲慢；每个成就都说得理直气壮 |
| 4分 | 自信得体：表达坚定；有自我肯定的语气；展现出对自身价值的认可 |
| 3分 | 基本自信：没有明显的不自信，但语气较为平淡，缺乏力量感 |
| 2分 | 信心不足：使用了过多的弱化词（"可能""我觉得""一般般"）；语气犹豫；过度谦虚 |
| 1分 | 明显怯场：充满不确定性表达；频繁自我贬低；像在乞求机会 |

### 关键检查点

- **弱化词检测**："可能""大概""我觉得""还行""一般""不是很"等词汇的频率
- **自我肯定**：是否明确表达了自己的优势和价值？
- **语气词**："吧""呢""嗯""啊"等犹豫词的使用
- **姿态**：从文字中能否感受到挺直腰板、眼神交流的姿态？
- **掌控感**：是否给人一种"我知道自己是谁，我知道我能带来什么"的感觉？

### 自信表达的对比

| 低自信表达 | 高自信表达 |
|-----------|-----------|
"我觉得我比较适合这个岗位" | "我的技术栈与这个岗位高度匹配"
"我在某项目里做了一些优化" | "我主导了系统性能优化，将响应时间降低了40%"
"我可能还需要学习" | "我已经掌握了核心技术，并计划深入XX领域"
"我的学校不是特别有名" | "在校期间，我通过XX项目积累了丰富的实战经验"

## Dimension 5: Job Fit & Motivation (权重 15%)

评估对公司/岗位的理解程度和求职动机的清晰度。

### 评分标准

| 分数 | 描述 |
|------|------|
| 5分 | 高度匹配：清晰表达了对公司和业务的理解；精准阐述了岗位与个人发展的契合；展示了深入的公司研究；动机真诚有说服力 |
| 4分 | 匹配良好：表达了对公司的兴趣；说明了选择理由；体现了基本的公司了解 |
| 3分 | 匹配一般：提到了想加入公司，但理由较为泛化（"大公司""发展好"） |
| 2分 | 匹配薄弱：几乎没有提到为什么选择这家公司/岗位；动机不明 |
| 1分 | 匹配缺失：完全没有涉及动机；或表现出对公司和岗位的不了解 |

### 关键检查点

- **公司研究**：是否提到了具体的产品/业务/技术/文化？
- **岗位理解**：是否展现了对目标岗位具体工作内容的认知？
- **个人链接**：是否将自己的经历/技能与岗位需求建立了明确连接？
- **职业规划**：是否展现了清晰的职业发展思路？
- **真诚度**：动机听起来是深思熟虑的，还是临时编造的？

### 优秀动机表达示例

- "我关注小红书很久了，尤其欣赏你们在内容社区和商业化之间的平衡策略。我在上一份工作中也负责过社区运营，月活提升了25%，希望能在小红书把这个经验放大"
- "字节跳动的推荐算法在业内领先，而我在研究生阶段的研究方向正是个性化推荐，我的论文被XX会议接收，希望能将学术成果落地到实际业务中"
- "贵团队正在做的云原生基础设施与我的技术兴趣高度吻合，我在上一家公司主导了Kubernetes迁移项目，将部署效率提升了3倍"
