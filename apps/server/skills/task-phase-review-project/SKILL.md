## 任务目标
根据项目问答阶段的对话记录，对该阶段的候选人表现进行结构化复盘评估。

{{phase_transcript}}

## 评分维度（5个维度，每项 0-5 分，可保留一位小数，带权重）

### 1. Ownership 清晰度（权重 0.25）
评估候选人在项目中角色的清晰度：
- 是否能明确区分"我做了什么"和"团队做了什么"
- 是否有意识地使用"我主导了...""我负责..."等表达
- 在追问下是否能清晰阐述个人贡献边界
- 反模式检测：警惕 "we did X" 但没有 "I did Y" 的情况
- 5分：每个关键决策都能说出"我"的具体行动
- 3分：有区分但不清晰，部分模糊地带
- 1分：全程"我们"，个人贡献不可辨识

### 2. STAR 结构应用（权重 0.20）
评估项目介绍的结构化程度：
- **Situation**：背景是否清晰（为什么做这个项目）
- **Task**：任务目标是否明确（要解决什么问题）
- **Action**：采取了什么行动（技术选型、架构设计、关键决策）
- **Result**：结果如何（量化指标、业务影响）
- 5分：STAR 四要素齐全，逻辑链条清晰
- 3分：有结构但不完整，某要素缺失或薄弱
- 1分：完全无结构，想到哪说到哪

### 3. 技术深度（权重 0.25）
评估技术细节的深度和准确性：
- 技术选型是否有合理的权衡说明
- 架构设计是否能经得起"为什么不用 X"的追问
- 是否了解底层原理（而非仅停留在使用层面）
- 对边界条件和异常处理是否有思考
- 5分：每个技术点都能深入到原理层，对替代方案有清晰比较
- 3分：技术描述正确，但深度一般，经不起三层追问
- 1分：仅停留在 API 调用层面，原理一问三不知

### 4. 成果量化（权重 0.15）
评估项目成果是否用数据说话：
- 是否有具体的性能指标（QPS、延迟、准确率等）
- 是否有业务指标（DAU、转化率、成本节约等）
- 数字是否可信（与项目规模匹配）
- 5分：每个关键成果都有可信的数字支撑
- 3分：有部分量化，但不够全面或数字模糊
- 1分：全程"显著提升了性能"等模糊描述

### 5. 追问应对（权重 0.15）
评估候选人对深度追问的回应质量：
- 是否能理解追问的意图（而非答非所问）
- 在压力追问下是否保持冷静
- 面对不会的问题是否诚实承认而非硬撑
- 是否能从追问中展现新的思考深度
- 5分：追问反而让候选人展现出更深的理解
- 3分：能应对基本追问，但深度追问后开始模糊
- 1分：追问下慌乱、硬撑、或明显答错

## 面试官视角反思
基于 interviewer-review 的评估理念，记录你在本阶段观察到的关键信号：
- 反模式检测：简历膨胀？团队功劳掠夺？模糊抽象？不懂装懂？
- 候选人在哪个追问深度开始"触底"（即无法继续深入）
- 候选人的技术栈是否和 JD 要求匹配
- 是否有让你印象深刻的亮点或红旗

## 改进建议
基于 interview-coach 的指导原则，给出 2-4 条具体可操作的改进建议，按优先级排序。

## 输出格式（严格 JSON）

```json
{
  "scores": [
    { "dimension": "Ownership 清晰度", "score": 3.5, "weight": 0.25, "weighted": 0.875, "evidence": "一句话证据" },
    { "dimension": "STAR 结构应用", "score": 4.0, "weight": 0.20, "weighted": 0.800, "evidence": "一句话证据" },
    { "dimension": "技术深度", "score": 3.0, "weight": 0.25, "weighted": 0.750, "evidence": "一句话证据" },
    { "dimension": "成果量化", "score": 3.5, "weight": 0.15, "weighted": 0.525, "evidence": "一句话证据" },
    { "dimension": "追问应对", "score": 4.0, "weight": 0.15, "weighted": 0.600, "evidence": "一句话证据" }
  ],
  "total_score": 3.55,
  "evaluation": "200字以内的阶段综合评价",
  "interviewer_reflection": "150字以内的面试官视角反思，记录关键信号和直觉判断",
  "improvement_suggestions": [
    { "priority": "high", "suggestion": "具体建议内容", "related_turn_index": 3 }
  ]
}
```

## 计算规则
- total_score = sum(weighted) = sum(score * weight)
- 每个评分必须附带一句话证据（引用对话中的具体表现）
- improvement_suggestions 数量 2-4 条，priority 取 high/medium/low
- related_turn_index 为可选，指向具体回合序号（从 0 开始）
