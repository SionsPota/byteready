## 任务目标
根据自由提问/技术问答阶段的对话记录，对该阶段的候选人表现进行结构化复盘评估。

{{questions}}

{{phase_transcript}}

## 评分维度（5个维度，每项 0-5 分，可保留一位小数，带权重）

### 1. 专业知识深度（权重 0.30）
评估候选人对专业领域知识的掌握程度：
- 基础概念是否准确（定义、原理、适用场景）
- 是否能解释"为什么"（底层原理、设计意图）
- 是否了解边界条件和限制
- 是否能区分相似概念（如 Redis 缓存穿透 vs 击穿 vs 雪崩）
- 5分：概念准确、原理清晰、边界明确、能举一反三
- 3分：基础概念正确，但深层原理理解有限
- 1分：概念混淆、原理错误、或完全不会

### 2. 逻辑思维（权重 0.20）
评估推理过程的清晰度和合理性：
- 回答是否有清晰的逻辑结构（总分、因果、对比）
- 从已知到结论的推导是否合理
- 面对复杂问题是否能分解为子问题
- 是否能识别假设条件和前提
- 5分：逻辑严密，每一步都可追溯，能处理多变量问题
- 3分：逻辑基本通顺，但某处有跳跃或遗漏
- 1分：逻辑混乱，前后矛盾，或完全发散

### 3. 问题理解准确度（权重 0.20）
评估候选人是否正确理解问题的意图：
- 是否准确抓住了问题的核心（而非回答表面的字面意思）
- 是否在回答前做了必要的澄清
- 是否区分了问题的类型（概念型、比较型、场景型）
- 5分：完全理解问题意图，甚至能指出问题的隐含假设
- 3分：基本理解正确，但某处有偏差
- 1分：答非所问，或完全误解问题方向

### 4. 回答针对性（权重 0.15）
评估回答是否切题、有重点：
- 回答是否直接回应问题（而非绕圈子）
- 是否有重点突出（而非平均用力）
- 是否避免了过度展开无关内容
- 5分：简洁有力，每句话都服务于问题的回答
- 3分：回答了问题，但有部分冗余或偏离
- 1分：大量无关内容，核心问题未触及

### 5. 沟通清晰度（权重 0.15）
评估技术表达的清晰易懂程度：
- 是否使用了恰当的比喻或类比帮助理解
- 术语使用是否准确且不滥用
- 复杂概念是否有分步解释
- 5分：能把复杂技术讲得让非技术背景的人也能听懂
- 3分：同行能理解，但表达不够精炼
- 1分：术语堆砌、表达混乱、或过于简略

## 面试官视角反思
基于 interviewer-review 的评估理念，记录你在本阶段观察到的关键信号：
- 候选人在哪些知识点上表现出"知道"vs"理解"的区别
- 是否有不懂装懂的迹象（猜测二元问题的答案）
- 面对不会的问题时的态度（诚实承认 vs 硬撑 vs 巧妙转移）
- 候选人的知识广度和深度是否符合岗位层级预期

## 改进建议
基于 interview-coach 的指导原则，给出 2-4 条具体可操作的改进建议，按优先级排序。

## 输出格式（严格 JSON）

```json
{
  "scores": [
    { "dimension": "专业知识深度", "score": 3.5, "weight": 0.30, "weighted": 1.050, "evidence": "一句话证据" },
    { "dimension": "逻辑思维", "score": 4.0, "weight": 0.20, "weighted": 0.800, "evidence": "一句话证据" },
    { "dimension": "问题理解准确度", "score": 3.0, "weight": 0.20, "weighted": 0.600, "evidence": "一句话证据" },
    { "dimension": "回答针对性", "score": 3.5, "weight": 0.15, "weighted": 0.525, "evidence": "一句话证据" },
    { "dimension": "沟通清晰度", "score": 4.0, "weight": 0.15, "weighted": 0.600, "evidence": "一句话证据" }
  ],
  "total_score": 3.575,
  "evaluation": "200字以内的阶段综合评价",
  "interviewer_reflection": "150字以内的面试官视角反思，记录关键信号和直觉判断",
  "improvement_suggestions": [
    { "priority": "high", "suggestion": "具体建议内容", "related_turn_index": 3 }
  ]
}
```

## 计算规则
- total_score = sum(weighted) = sum(score * weight)
- 每个评分必须附带一句话证据（引用对话中的具体表现）
- improvement_suggestions 数量 2-4 条，priority 取 high/medium/low
- related_turn_index 为可选，指向具体回合序号（从 0 开始）
