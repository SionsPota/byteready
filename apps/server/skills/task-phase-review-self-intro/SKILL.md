## 任务目标
根据自我介绍阶段的对话记录，对该阶段的候选人表现进行结构化复盘评估。

## 评估背景
- 岗位：{{position}}
- 目标公司：{{target_company}}
- 岗位描述（JD）：{{job_description}}
- 本阶段对话轮次：{{turn_count}}
- 本阶段用时：{{elapsed_minutes}} 分钟

## 阶段对话记录
{{phase_transcript}}

## 评分维度（5个维度，每项 0-5 分，可保留一位小数，带权重）

### 1. 结构完整性（权重 0.25）
评估自我介绍是否包含完整的结构要素：
- **开场钩子**：是否有吸引人的开场（非简单"我叫XXX"）
- **教育/经历**：教育背景和工作经历的呈现逻辑
- **关键项目**：是否提及与岗位相关的核心项目
- **岗位动机**：为什么选择这个岗位/公司
- **收尾**：是否有得体的结尾
- 5分：5个要素齐全且流畅衔接
- 3分：3-4个要素，衔接一般
- 1分：要素缺失严重或逻辑混乱

### 2. 信息相关性（权重 0.20）
评估内容的针对性和信息密度：
- 是否聚焦与岗位相关的经历
- 有无冗余信息（如与岗位无关的爱好过多）
- 信息密度是否适中（不空泛也不过载）
- 5分：每一句话都对岗位有价值，零冗余
- 3分：整体相关，但有 1-2 处冗余
- 1分：大量无关信息，或过于空泛

### 3. 表达自然度（权重 0.20）
评估语言表达的流畅性和真实感：
- 是否有明显的背诵/朗读痕迹
- 语气是否自然、有交流感
- 过渡是否平滑（非生硬的"下一点是..."）
- 5分：像与朋友的自然对话，有眼神交流感
- 3分：整体流畅，偶有生硬处
- 1分：明显背诵，机械感强

### 4. 岗位匹配度（权重 0.20）
评估内容与岗位要求的契合程度：
- 是否突出岗位所需的核心技能
- 经历描述是否指向岗位能力模型
- 是否暗示了"为什么选我"的理由
- 5分：听完就知道"这就是我们要的人"
- 3分：有相关经历，但匹配度一般
- 1分：听完不知道和岗位有什么关系

### 5. 时间控制（权重 0.15）
评估自我介绍的时长把握：
- 1-2 分钟为理想区间
- 过短（<40秒）：信息不足，显得准备不充分
- 过长（>3分钟）：面试官会不耐烦，重点被稀释
- 5分：时长适中，节奏紧凑
- 3分：略长或略短，但不影响整体
- 1分：严重超时或过于简短

## 面试官视角反思
基于 interviewer-review 的反模式检测，记录你在评估过程中观察到的关键信号：
- 是否有简历膨胀的迹象（声称与后续回答不符）
- 是否有过度谦虚或过度自信的信号
- 开场的第一句话是否建立了良好的第一印象
- 候选人的自我认知与实际表达是否一致

## 改进建议
基于 introduction-coach 的指导原则，给出 2-4 条具体可操作的改进建议，按优先级排序。

## 输出格式（严格 JSON）

```json
{
  "scores": [
    { "dimension": "结构完整性", "score": 3.5, "weight": 0.25, "weighted": 0.875, "evidence": "一句话证据" },
    { "dimension": "信息相关性", "score": 4.0, "weight": 0.20, "weighted": 0.800, "evidence": "一句话证据" },
    { "dimension": "表达自然度", "score": 3.0, "weight": 0.20, "weighted": 0.600, "evidence": "一句话证据" },
    { "dimension": "岗位匹配度", "score": 3.5, "weight": 0.20, "weighted": 0.700, "evidence": "一句话证据" },
    { "dimension": "时间控制", "score": 4.5, "weight": 0.15, "weighted": 0.675, "evidence": "一句话证据" }
  ],
  "total_score": 3.65,
  "evaluation": "200字以内的阶段综合评价",
  "interviewer_reflection": "150字以内的面试官视角反思，记录关键信号和直觉判断",
  "improvement_suggestions": [
    { "priority": "high", "suggestion": "具体建议内容", "related_turn_index": 3 }
  ]
}
```

## 计算规则
- total_score = sum(weighted) = sum(score * weight)
- 每个评分必须附带一句话证据（引用对话中的具体表现）
- improvement_suggestions 数量 2-4 条，priority 取 high/medium/low
- related_turn_index 为可选，指向具体回合序号（从 0 开始）
