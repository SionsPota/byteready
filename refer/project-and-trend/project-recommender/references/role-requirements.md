# Role Requirements Matrix

Skill expectations by role archetype for gap analysis.

## Frontend Engineer

**Core**: React/Vue/Angular, TypeScript, CSS/Tailwind, state management, performance optimization
**Expected Projects**: Component library, design system, real-time dashboard, PWA, micro-frontend
**Portfolio Gaps**: SSR/SSG, testing strategies, accessibility, internationalization, performance budgets

## Backend Engineer

**Core**: API design, database optimization, caching, message queues, distributed systems patterns
**Expected Projects**: High-concurrency API, distributed cache, event-driven system, rate limiter, search engine
**Portfolio Gaps**: Kubernetes deployment, observability, CI/CD pipelines, security hardening

## Full-stack Engineer

**Core**: End-to-end architecture, database design, frontend framework, deployment
**Expected Projects**: SaaS application, real-time collaboration tool, e-commerce platform, CMS
**Portfolio Gaps**: Payment integration, multi-tenancy, analytics, mobile responsiveness

## AI/ML Engineer

**Core**: Model training, deployment, RAG, vector databases, prompt engineering
**Expected Projects**: Document Q&A system, recommendation engine, image classifier, NLP pipeline
**Portfolio Gaps**: MLOps, model monitoring, A/B testing, cost optimization, edge deployment

## Data Engineer

**Core**: ETL/ELT, data warehousing, streaming, SQL optimization, data modeling
**Expected Projects**: Real-time pipeline, data warehouse, CDC system, data quality framework
**Portfolio Gaps**: Data governance, lineage tracking, cost optimization, streaming analytics

## DevOps/SRE

**Core**: Kubernetes, IaC, CI/CD, observability, incident response
**Expected Projects**: GitOps pipeline, chaos engineering platform, internal developer platform, cost optimizer
**Portfolio Gaps**: Security scanning, disaster recovery, multi-region deployment, FinOps

## Product / 综合岗

**Core**: Data analysis, A/B testing, growth metrics, SQL, Python, dashboarding
**Expected Projects**: A/B testing framework, growth dashboard, automated reporting, user segmentation
**Portfolio Gaps**: Experimentation platform, causal inference, product analytics, data visualization
